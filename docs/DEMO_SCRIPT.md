# Five-minute demo script

1. Open the dashboard and explain the task lifecycle.
2. Submit: `Process the latest invoice from Acme Supplies`.
3. Show that the document is read and fields are extracted.
4. Explain why the task pauses: the amount crosses the configured approval threshold.
5. Approve the task.
6. Show the persisted invoice and independent read-back verification checks.
7. Submit the same request again and show duplicate detection.
8. Submit: `Process the latest invoice` and show that the system asks for a vendor instead of guessing.
9. Open the task audit trail and point out the execution evidence.
10. Explain the limits honestly: this is a sandbox prototype, not a production finance integration.
